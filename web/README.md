# 前端源码

`index.html` 就是**完整的前端**——不是演示片段。
HTML、CSS、JavaScript 全在这一个文件里，四千多行，没有构建步骤、
没有依赖、没有 node_modules。改完刷新就生效。

## 这一版新加的

- **「今天」页**（抽屉第一项，或点顶栏他的名字）：他夜里留的话、心情打卡（选完他回一句）、
  日历 + 清单合成的今日时间线（带"现在"那条线，能直接勾完成）、睡眠 / 步数 / 日报头条 / 共读进度、
  一键跟他说。全走现成接口，后端不用加东西。
- **顶栏那行小字**改成他此刻的状态：在家 / 在想… / 正在说… / 睡着了。
- **名字可配**：脚本里 `const HOME = { me, him, since }`，清单、日记、今天页都跟着变。
- **演示数据 v2**：接口形状和真代码对齐，每一页都有内容；还能真聊——发一句他会流式回
  （"今天有什么安排""提醒我…""放首歌""好累"会走不同回法），待办 / 便条 / 心情都能改。
- 修了三个真 bug：日历点开必报错（拆生理周期时漏了一个变量）、"另一位"那间纯文字回复是空泡、
  重放历史后顶栏一直显示"正在说"。小螃蟹的图不在时整只藏起来，不挂裂图。

## 第二轮（参考小红书 / 抖音上大家的自建前端）

- **接入 API 重做**：原来那页样式整块丢了，POST 没带 JSON 头，不看状态码（后端 500 也说"接上了"）。
  现在有 官方直连 / OpenRouter / 中转站 三个预设；地址自动去掉结尾的 `/v1`；「接过去」会先自己试一次，
  不通就停下说清楚原因（401 令牌不对 / 404 地址或模型名 / 429 额度…），确定要接再点「硬接」；
  可以另外配中档、快档模型；已存的令牌显示尾号。
- **动态**：他会发，你点赞、评论；你也能发。
- **心愿**：券包（他送你的券可以"用掉"，你也能送他）+ 愿望单。
- **专注**：他陪你的番茄钟，关了页面也接着走，做完一键告诉他。
- **聊天时间戳**：隔半小时以上才插一行小字。**空窗口**不再空着，按时间说一句（"这么晚，是想我了吗"）。
- **今天页加天气**。

新接口（演示数据里都有；后端没实现的，对应那块就不显示或提示没拿到）：

```
GET  api/moments  → { items:[{ id, who:'gu'|'her', text, at, likes:['her'], comments:[{who,text,at}] }] }
POST api/moments  { action:'post', text } | { action:'like', id } | { action:'comment', id, text } | { action:'del', id }  → 同 GET

GET  api/wishes   → { coupons:[{ id, from:'gu'|'her', title, note, used_at? }], wishes:[{ id, who, text, at, done_at? }] }
POST api/wishes   { action:'use', id } | { action:'give', title, note } | { action:'wish', text }
                  | { action:'wish_done', id } | { action:'del', kind:'coupon'|'wish', id }  → 同 GET

GET  api/weather  → { ok, city, now:{ t, text }, hi, lo, tip }
POST api/focus    { minutes, task, done }   （只是留账，可不实现）

接入 API（接口没变，多了几个可选字段）：
GET  api/authmode → { mode:'api'|'sub', base, token_tail?, models:{ model_opus, model_sonnet?, model_haiku? } }
POST api/apitest  { base, token, model_opus, model_sonnet, model_haiku, preset } → { ok, model?, ms?, url, code?, detail? }
POST api/apiconf  同上 → { ok, mode, base }；{ clear:true } 退回订阅
```

演示里想看 API 报错长什么样：令牌里带 `bad` 是 401，地址里带 `wrong` 是连不上，模型名带 `nope` 是 404。

## 第三轮：有后端了

`server/` 里是完整的后端（只用 Python 标准库），`python3 server/app.py` 就能跑，详见 [server/README.md](../server/README.md)。

- **演示模式只在双击打开（file://）或网址带 `?demo` 时启用**；从后端打开就走真数据。
- **接入**：官端订阅 / 官方 API / OpenRouter / 中转站四条路；先「拉取模型」再点选，中档快档可选。
- **右上角三个点**全部能用：新窗口、窗口列表、搜索、容量（真算的）、备注、收纳。
  原来「备注」「收纳」用的是浏览器原生 prompt / confirm，在添加到主屏幕的网页里会被吞掉，换成了页内弹窗。
- **选模型面板**跟着线路走，不再写死。
- 设置里新加：名字和地点（含时区、天气城市、推送兜底）、他的人设、现在让他醒一次。
- 共读能放书，日报没送到时能叫他现在排一份，推送没装好时会说清楚怎么办。
- 时间不再写死北京时间：跟设置里的时区，不填就跟设备走。

## 第四轮：记忆、信、工作间、后台

参考了一圈大家自建前端的帖子和开源项目之后加的（只借想法，没有搬代码，名单见 [00-原作者名单](../00-原作者名单.md)）：

- **记忆页**：每天一圈涟漪（大小＝那天记得多，颜色＝冷暖，线型＝种类）；「投一颗石子」就是搜索，
  对不上会老实说不记得；按天跳、按种类筛；亲手记一件、改、标「记错了」、删；上面挂着「没聊完的」线头。
- **信箱**：写给他或者写给以后的信，可以封到明天、一周、一个月、一年后或者指定那天。
- **工作间**：在手机上让电脑上的 Claude Code 干活（读写文件、跑命令），能接上电脑上以前的会话。
- **设置 → 后台**：一键自检、后台任务（失败三次自动停下并告诉你）、现在整理记忆、白天想你开关、
  claude.ai 连接器地址和步骤、一键备份、最近发生的事。
- 聊天里他在你不在时做的事会变成一行小字；白天他主动说的话直接出现在聊天里。
- 发送失败：话放回输入框，下面一行红字点一下重发。

## 第五、六轮：网页自己就能用 + 帖子里的功能补齐

**本机模式**：在 GitHub Pages 上打开（或者双击 index.html），设置 → 接入 填上你的 API（官方 / OpenRouter / 中转站都行，中转站要允许网页直连），
他就真的会回你——浏览器直接连 API，聊天、记忆、清单、日记、信全存在这台设备的浏览器里（`web/local.js`）。后台页可以下载备份、从备份恢复。
想要关掉网页他也能醒、能推送、能用官端订阅（Claude Code），就在电脑上跑后端。

新加的：
- 聊天：回答分段（像发消息）、每条回复下面的参数（模型 · token · 用时）、长按气泡（复制 / 引用 / 收藏片段 / 读出来 / 存为表情）、表情包、按住说话、**打电话**、头像、夜面（翻到夜里那一面）、仪表（上下文圆环、用量、一键换模型）
- 一起听（网易云）、一起看（B 站 / YouTube）——他知道你在听什么、看什么
- 我们：两个人的头像、在一起第几天、几个数字、里程碑时间线
- 记忆页：每日 / 一周回声、收藏的片段、他推给你的每一条
- 日记：双人日记（同一天他写的和你写的并排，顶上一周的日子条）；夜记里多了他写的梦
- 玩：海龟汤、你画我猜（画板直接发给他猜）、抽卡写故事、真心话
- 世界书：关键词一出现，对应设定就放进他的上下文
- 通知页：装到主屏幕 → 允许通知 → 订阅，三步走；兜底用 Bark / ntfy

## 第七轮：他自己过日子

- **连发**：他正在回的时候你再发几句，不打断，先上屏、先存下，他说完这句接着一起回。
- **动态互通**：你发的动态他看得见；你发了、评论了，他会自己来点赞或回一句；他也会自己发；你们能互相评论点赞。
- **白天他自己在家**：你超过 45 分钟没说话，他会看看家里，做零到两件事（评论你的动态、发条动态、留便条、送券、点首歌、记个日子……），有想说的就说一句，没有就 PASS。两小时最多一次、一天最多五次，默认开着（设置 → 后台 可以关）。
- **点歌不用你导入**：跟他说「给我点首歌」，他点的歌会变成歌卡，一起听页里有歌单；网易云链接只是备选。
- **拍一拍 / 摸摸他**：右下角的小团子点一下有反应，连点两下是拍一拍，他真的会回。
- **哄睡**：他讲一个故事读给你听，10/15/20/30 分钟到点自己停。
- **关掉页面也能响**（能做到的部分）：填了 ntfy 地址之后，近三天到点的提醒、信到期会提前排进 ntfy，页面关着也会推。他「想你」这类临时起意的消息，页面关着时要后端在跑才推得出来——网页没法在关掉之后自己跑，这是浏览器的限制，不是设置问题。

## 直接打开就能看

在线看：仓库开了 GitHub Pages，打开 `https://<你的用户名>.github.io/<仓库名>/` 就是演示版。

不用接任何后端。而且它**不会向外发出任何请求**——
所有 `api/` 调用都被那份演示数据拦下了。

## 接你自己的后端

从后端（`python3 server/app.py`）打开就走真接口。

需要你实现的接口，在各功能文档里都写了。
