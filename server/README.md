# 后端

只用 Python 标准库（3.9 及以上），不用装任何依赖。一个命令就能跑：

```bash
python3 server/app.py
# 打开 http://这台机器的地址:8787
```

页面和接口在同一个端口上：`web/` 里的文件当网页发，`/api/...` 是接口。
直接双击 `web/index.html` 打开时还是演示模式；从后端打开就走真数据。

## 第一次打开之后

1. **设置 → 接入（线路和模型）**，四条路选一条：
   - **官端订阅**：用这台机器上 Claude Code 的登录（你的 Claude 订阅额度），不要令牌。
     先在机器上装好 Claude Code（`npm i -g @anthropic-ai/claude-code`），运行一次 `claude` 登录。
   - **官方 API**：Anthropic 控制台的 key，按量计费。
   - **OpenRouter**：openrouter.ai 的 key。
   - **中转站**：中转给你的地址和 key（地址末尾的 `/v1` 不用写）。

   然后点 **拉取模型** → 点一个当主模型（中档、快档可选）→ **试一试** → **接过去**。
   「接过去」会先自己试一次，不通会停下说清楚原因。
2. **设置 → 名字和地点**：他怎么叫你、他叫什么、在一起那天、城市（天气用）、时区。
3. **设置 → 他的人设**：他每次开口前先读的那一段。日程、清单、身体这些不用写，每次会自动附上。

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `HOME_PORT` | `8787` | 端口 |
| `HOME_HOST` | `0.0.0.0` | 监听地址；只想本机用就写 `127.0.0.1` |
| `HOME_PASSWORD` | 空 | 设了就要输密码（浏览器弹框，用户名随便填）。**放到公网一定要设** |
| `HOME_DATA` | `server/data` | 数据放哪 |
| `HOME_LOG` | 空 | 设成 1 打印每个请求 |

放到公网时建议前面套一层 HTTPS（Caddy 一行就行：`your.domain { reverse_proxy 127.0.0.1:8787 }`）。
iPhone 上「添加到主屏幕」和网页推送都要求 HTTPS。

## 他能做什么

两条路都能让他动手：往清单、日历里加事，贴便条，发动态，送券，挂愿望，摘你说过的话，写日记，回共读批注，推通知到你手机，
翻记忆、记一件事、写信、把聊完的线头划掉。他在你不在的时候做了什么，聊天里会多一行小字。

- **API 线路**：工具调用（tool use），聊天里会显示「Used add_todo」。
- **官端订阅**：他在 Claude Code 里用 Bash 跑 `python3 server/app.py tool add_todo '{"text":"…"}'`。
  权限只放了这一条命令和上网查东西的 WebSearch / WebFetch。
  官端订阅的他是**常驻**的：一个 Claude Code 进程一直开着，每句话从标准输入送进去（`--input-format stream-json`），
  不用每句都重新起一个进程；进程没了会自动接回同一个会话。人设和规矩写进文件传进去，不塞命令行（太长会报 E2BIG）。
  你的话**先落库再生成**，生成失败也不会丢。

你在家里做的事（勾掉清单、记心情、评论他的动态、用掉一张券、在共读里划线、传文件……）
会攒进一个小匣子，他下一次开口前会看到，所以不用你再跟他说一遍。

## 记忆

他有一本自己的记忆，放在 `server/data/memory.json`。两种方式写进去：

- **聊天里**：他觉得重要就调 `remember`，必须附上你原话里的一句（`quote`）；
  后台检查这句话真的出现在你说过的话里，编的不收。
- **后台整理**：攒到 60 句、或者安静 90 分钟、或者跨了一天，他会把这段对话整理一次：
  写一份对话时间线，挑出值得记的事，记下没聊完的线头。整理用的是单独一次调用，
  不带工具；整理不成功游标不往前走，下次接着整理同一段，不丢。

翻记忆（`memory_search`）是关键词 + 字面相似 + 关联三路一起找，再按「常被想起」加权。
**对不上就是对不上**：低于门槛直接回「没有可靠命中」，不拿沾边的去圆。
你说话时他也会顺手翻一下（12 小时内同一件不重复想起，每次最多带 1KB），翻到了会放在这句话前面给他看。

记忆页里：涟漪是每一天（圈大＝那天记得多，颜色＝冷暖，线型＝种类），
上面的「投石子」就是搜索，结果和他看到的一样。你可以亲手记一件、改、标「记错了」（他就看不到了）、删掉。

## 续接（换口气）

上下文用到窗口的 60% 左右（或者你在设置里指定的条数），他会先把没整理的对话整理掉，
再开一个新会话，**原样**带上最近两万多字（不做摘要，摘要会把语气磨平），
加上没聊完的线头和最近的记忆。你那边看不出断过。

## 信箱

可以封到某一天才拆的信。封着的信，后端连正文都不发给前端；到日子了他和你都会收到提醒。
他也能写（`write_letter`），有时候会给你封一封。

## 工作间（Claude Code）

抽屉里「工作间」是另一条线：在这台机器的某个文件夹里开一个 Claude Code，
你在手机上说要做什么，它去读文件、改代码、跑命令。会话是常驻的，
也能接上这台电脑上以前的 Claude Code 会话。

- 需要这台机器装好 `claude` 并登录过。
- 默认权限是「改文件不问，其余要问」（`acceptEdits`），工具只放了读写文件和命令行、上网查。
- **只在你自己信任的机器和文件夹上用**：它真的会动文件。后端一定要设 `HOME_PASSWORD`。

## 让 claude.ai 那边的 Claude 也认得你（连接器）

后端带一个 MCP 端点（Streamable HTTP），地址在 设置 → 后台 → 连接器 里，形如
`https://你的地址/mcp/<钥匙>`。在 claude.ai 设置 → 连接器 → 添加自定义连接器，贴进去，OAuth 留空。
那边的 Claude 就能：开场先读一份「家里现在怎样」（`home_session_start`）、翻同一份记忆、
记新的事、看最近的聊天和今天的日程、给这里留便条、加待办。
工具改了那边不刷新时，在地址末尾加 `?v=2` 重新添加一次。

- 地址里的钥匙就是权限，**别发给任何人**。也可以用 `Authorization: Bearer <钥匙>`。
- 后端得能从外网访问（Cloudflare Tunnel、frp 都行），localhost 那边连不上。
- 那边的对话内容会经过 claude.ai，按那边的隐私条款处理。

## 后台、自检、备份

设置 → 后台：

- **一键自检**：问他一句「我是谁」、调一次工具、看常驻会话和后台任务。出问题先按这个。
- **后台任务**：每个任务上次成功是什么时候。同一个任务连着失败三次就停下来、推一条通知给你，
  不会每十分钟重试到天亮；修好之后点「继续」。
- **备份**：一个按钮把整个家打包成 zip（不含令牌和推送私钥）。
- **最近发生的**：只记做了什么（用了哪个工具、醒没醒），不记你们说了什么。

## 自己会动的

- **夜里的心跳**：23:30 到 06:30 之间，你超过 40 分钟没说话，他会醒来，一晚上最多两次，两次之间隔 3 个多小时。
  醒来会写一段夜记，可能发条动态、留一句早上给你看的话；第一次醒的时候还会把这一天写进日记。
  设置里能关；「现在让他醒一次」可以立刻试一下。
- **到点提醒**：待办设了时间的，到点前后会推一条。信到日子了也会推。
- **白天想你**（默认关，设置 → 后台里开）：你超过 50 分钟没说话，他会想想要不要找你；
  没有真想说的就回 PASS，什么都不发。一天最多 3 次，间隔至少 3 小时——频率写在代码里，不靠提示词。
- 推送和发动态也有硬冷却（推送 2 小时 / 一天 6 条，动态 3 小时 / 一天 3 条）。
- **早报**：每天 6 点到 11 点之间，如果今天还没有报纸，他会排一份。官端订阅能上网查新闻；
  API 线路上不了网，会从家里的事里挑。日报页没有报纸时，也可以点「现在排一份」。

## 推送

两条腿，有一条就会响：

1. **网页推送**：`pip install pywebpush`，重启后端，设置里打开「手机通知」。
   iPhone 要先「添加到主屏幕」，从那个图标进来才能开。
2. **兜底**：设置 → 名字和地点 → 推送兜底地址，填 Bark（`https://api.day.app/你的key`）或 ntfy（`https://ntfy.sh/你的频道`）。

## 手表数据

身体页右上角有网址和钥匙。手机快捷指令「获取健康数据 → 组成 JSON → POST」：

```
POST https://你的地址/api/health
Authorization: Bearer <钥匙>
{"sleep_hours": 6.2, "steps": 8000, "resting_heart_rate": 61, "device": "Apple Watch"}
```

字段名见 `server/home.py` 里的 `UNITS`；不认识的字段会跳过。

## 共读

书架页点「放一本书」传 txt / md（GBK 编码的 txt 也认），会按「第 X 章」或 `#` 标题自动分节。
也可以直接把 txt 丢进 `server/data/books/`。

## 数据

全在 `server/data/`：聊天记录是 `home.db`（SQLite），其余每样东西一个 json。
`secret.json`（令牌、手表钥匙）只有本机用户能读。备份就是复制这个文件夹。
这个文件夹已经在 `.gitignore` 里，别把它提交上去。

## 接口一览

前端调用的每个接口，后端都实现了。返回格式写在 `web/README.md` 和各功能文档里，
代码里也按页面分好了：`app.py`（路由和零碎接口）、`home.py`（家里的东西）、`engine.py`（他怎么说话、工具、心跳、早报）、`core.py`（存储、事件流、推送）。
